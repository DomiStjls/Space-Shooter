# Space Shooter

Игра на Pygame — проект второго года Яндекс.Лицея.

## Запуск

Установите Python, затем выполните из папки проекта:

```bash
git clone https://github.com/DomiStjls/Space-Shooter.git
cd Space-Shooter
pip install -r requirements.txt
python main.py
```

Для работы файлы `main.py`, `game.py` и папка `data/` должны оставаться в составе проекта.

## Структура и материалы

- `main.py` и `game.py` — код игры.
- `data/` — изображения, звуки и файлы уровней.
